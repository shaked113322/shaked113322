# Install / Deploy

1. Open your special GitHub profile repository: https://github.com/shaked113322/shaked113322
2. Upload `README.md` to the repository root, replacing the old README.
3. Upload the entire `assets/` folder to the repository root alongside it.
4. Commit the changes. Your GitHub profile updates automatically.

File tree:

```text
shaked113322/
  README.md
  assets/
    hero.svg
    signal.svg
    flagship.svg
    footer.svg
```

The artwork is original, self-hosted SVG. No JavaScript, tokens, Actions, or hosting service is required for these four graphics. Subtle CSS animation is optional and honors reduced-motion preferences. The external skills, badges and GitHub telemetry use third-party image services and may be unavailable at times without impacting the main layout.
